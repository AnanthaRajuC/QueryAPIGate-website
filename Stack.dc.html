The tech stack, layer by layer

Well-known, widely deployed components at every layer. Optional pieces are pip extras, imported only when a feature that needs them is in use, so a server carries only what it runs.

How the stack is kept healthy

Dependencies

Few at the core

The core needs four packages: Flask, Werkzeug, PyYAML and openpyxl. Drivers, MCP, JWT, Redis, tracing and AWS are extras you add when you use them.

Install and extras →
Versions

Oldest versions tested

CI runs the suite on the lowest allowed version of every core dependency and of the mcp, jwt and redis extras, so every minimum in the package metadata is one that works.

Supply chain

Pinned and signed

Base images pinned by digest and every GitHub Action by commit. Releases signed with cosign, with SLSA provenance and an SPDX SBOM listing what is inside.
