Client libraries

A typed client in your team's language, generated in one command

Every server publishes a complete OpenAPI 3.0 spec, checked against the official validator in CI, with each saved query as its own typed endpoint. Point OpenAPI Generator at it and get a client in any of its roughly 50 languages: methods named after your queries, parameters typed from their rules, nothing written by hand.

TypeScript✓Python✓Java✓GoC#KotlinSwiftRustPHPRubyDartScala+ about 40 more

✓ generated and called against a live server. Generate with a partner's key and their client contains only the queries that key may call. Regenerate when you publish a new query version.

Governance

Governed, not just exposed

Read-only by default. A single-statement SQL guard blocks writes and multi-statement injection unless a connection or key explicitly opts in, narrowed further to specific write operations if needed.

The security model →

Identity

Scoped API keys, reusable roles, named administrators with owner, admin, developer and auditor roles. App users by JWT / JWKS.

Policy

Per-query and collection grants, table allow-lists, write ceilings, per-user values bound from token claims, rate limits, IP allow-lists, key expiry.

Masking

Column masking traced to source columns through joins and aliases with sqlglot, applied before the response is formatted.

Record

Audit log of who changed what, run history for every query, alerts on failures, Prometheus /metrics.

Your data

Every major database, one interface

Native drivers, plus generic JDBC for anything with a driver jar. Point a connection at a folder or bucket of Parquet, CSV or JSON and each file becomes a view, through DuckDB.

Run it

A running server in minutes, wherever you run things

The same server three ways. Load the examples and the first request works at once: a small generated database and four worked APIs. The image and the chart are signed, with provenance and an SBOM. Reference architectures and measured performance →

pip

On your machine

Python 3.11 or later. SQLite included; add drivers as extras.

$ pip install queryapigate
$ export QUERYAPIGATE_API_KEY=demo-key
$ queryapigate examples load
$ queryapigate serve
# http://127.0.0.1:5000 · Console at /console

docker

In a container

Every driver except H2, plus Redis, MCP and tracing. -h2 tags add Java for H2 and JDBC.

$ docker run -p 5000:5000 \
    -v queryapigate-data:/data \
    -e QUERYAPIGATE_API_KEY=change-me \
    ghcr.io/anantharajuc/queryapigate:0.34.2

# several instances behind Caddy
$ docker compose up -d

helm

On Kubernetes

One pod on SQLite, or several on PostgreSQL and Redis. Non-root, read-only root filesystem.

$ kubectl create secret generic queryapigate \

    --version 0.34.2 \
