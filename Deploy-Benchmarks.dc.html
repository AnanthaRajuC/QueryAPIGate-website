05 · Source and image

Which build each number came from

Source or image matters for Python.

Most rows were measured from source, on the laptop's Python 3.12.3. The Docker image's Python, from python:3.12-slim, links against a shared libpython and is about 30% slower per CPU for every call Python handles (BACKLOG #104). The image's Rust data plane serves at 0.95-0.99× the from-source build. So data-plane rows carry over to the image, and Python-only rows overstate what the container does today.

06 · How it's measured

Measured, not promised

  • One 20-thread laptop on AC power, with the performance profile.
  • The gateway, the database and the load generator each pinned to their own cores: gateway 0-7, database 8-11, load 12-19.
  • Builds take turns in rotating order: 5 rounds per comparison; 3 for the run store cells and the data plane's 64-caller block.
  • A difference counts only when the min-max ranges don't overlap.
  • Open-loop load at fixed rates for latency, corrected for coordinated omission; closed-loop for throughput.
  • A /health check before and after every block.
