Every major database, one interface

Saved queries, grants, masking, limits and the audit log work the same on every connection. Tier 1 types are under the compatibility promise and tested against the real database in CI; experimental types work, with the gaps the support matrix lists.

Pooling and time limits

Idle connections kept per connection, QUERYAPIGATE_POOL_SIZE, and a query time limit enforced on every front door (on every database type but generic JDBC), lowered per key or per request with ?timeout.

Guide 37 →

TLS to the database

PostgreSQL's sslmode and MySQL's ssl_* settings are passed to the driver: a connection that asks for a verified certificate fails rather than connecting without one.

No passwords in the store

Passwords as ${VAR} references or encrypted at rest under a key you can rotate; or short-lived credentials from Vault or RDS IAM Exp.

Guide 56 →

Ad-hoc SQL, governed

POST /execute_sql for keys that are allowed it: one statement, read-only unless granted, confined to allowed_tables, and recorded like any saved query.

02 · Build

From a SQL statement to a documented endpoint

Saved queries as endpoints

Each saved query is versioned, has typed parameters with ranges and lengths, and keeps a run history. OpenAPI and a Postman collection are generated, and OpenAPI Generator turns the spec into a typed client in about 50 languages. Group queries into collections and grant access to the whole collection at once.

curl
$ curl 'http://127.0.0.1:5000/q/example_top_films?top_n=2&category=Comedy&format=csv' \
    -H 'X-API-Key: demo-key'
title,category,rating,rentals,rank
Electric Signal,Comedy,PG,977,1
Crimson Garden,Comedy,PG-13,631,2
query_parameters.json
// query_parameters
{
  "rating":     {"type": "str", "enum": ["G","PG","R"], "default": "PG"},
  "max_length": {"type": "int", "min": 1, "max": 600},
  "title":      {"type": "str", "required": false, "pattern": "[A-Za-z ]+"},
  "customer":   {"type": "int", "from_claim": "sub"}
}
Try itEdit the values. The checks below run exactly as the rules above say, before anything reaches the database.
response
$ curl '/q/films?{{ tp.qs }}' -H 'X-API-Key: demo-key'
{{ tp.status }} {{ tp.body }}

Typed parameters, checked before the database

Each :name in the SQL is a bound parameter with a type, bounds, length, enum, pattern and default. A request that breaks a rule gets a 400 listing every problem and never reaches the database. from_claim takes a value from the caller's sign-in token instead of the request, so a user can only ever ask for their own rows.

Versions, drafts, publishing

Every saved query has at most one published version: the one /q/<name> runs and the one OpenAPI, MCP and Postman describe. Newer versions are drafts, invisible to callers until published; the admin key can test one by number. Roll back to any earlier version. Older versions stay runnable with ?version=.

03 · GovernPathGive a partner an API →

Access control, per key, decided before any query runs

A key identifies an application. Every grant below narrows what that key reaches; roles bundle a shape of grants into a reusable template. Writes are off by default.

ControlSettingWhat it narrows
Whole connectionconnectionsEvery saved query on it, plus ad-hoc SQL if allowed.
Curated endpointsqueries · collectionsName the saved queries a key may run, one at a time or as a collection. Nothing else answers.
Table allow-listallowed_tablesAd-hoc SQL confined to named tables; the SQL is parsed, not pattern-matched.
Column maskingmaskHash, mask, null or drop named source columns. Traced through aliases, CTEs and joins; refused rather than served unmasked.
Write granularityallowed_write_opsWrites off by default. Turn on only INSERT, or UPDATE on one query.
Budget and originrate_limit · allowed_ipsA per-key request budget and a list of IPs or CIDR ranges the key may call from.
Lifecycleexpires_at · last_used_atTime-boxed keys for trials and contractors; alerts before expiry and for keys gone unused.
Signed-in usersAuthorization: BearerAccept the JWT your app already has (Auth0, Cognito, Keycloak, Azure AD or your own secret). Each user calls as themselves, mapped to a role.
Fair sharesmax_concurrent · query_timeout · max_rowsCap the queries a key runs at once, how long each may run and the rows a call returns, across every instance. Over it: 429 too_many_concurrent.
Usage quotasquotaCalls and rows per day or month, with X-Quota-Remaining-* headers on every response and an alert before it runs out.
Secret rotationrotateReissue a key's secret while the old one keeps working for a grace period, or zero for a leaked one.

04 · DeliverPathShip data out →

Formats, channels and the Console that manages it all

Eight output formats

JSON, NDJSON, CSV, TSV, XML, YAML, XLSX and Parquet. Paginated for typical results; constant-memory streaming with ?stream=true for exports too large to hold in memory.

MCP for AI agents

queryapigate mcp exposes saved queries as tools with structured results, ad-hoc tools where allowed, and table and column descriptions. AI clients sign in with OAuth 2.1 through your identity provider, or an API key. Usage is recorded per agent, and write tools wait for a person's approval.

Live events

Server-sent events as queries run, per key if you want. queryapigate events reads every instance's runs from the shared store, woken by a PostgreSQL notification.

Scheduled exports

queryapigate export writes a full result to a file, in-process. Atomic rename on completion, non-zero exit on failure, deliveries to S3, GCS, R2 or disk that resume where the last run stopped.

Files as tables

Point a connection at a folder or bucket of Parquet, CSV or JSON and each file becomes a view through DuckDB, locked to the paths that connection allows.

Response cache

A per-query cache_ttl, in-process by default. With Redis, one cache shared by every instance, surviving restarts.

The Console

Manage connections, saved queries, API keys and roles. Run ad-hoc SQL with a schema browser. Review the audit log and alerts, approve agents' writes, manage administrators, exports and quotas, and see who can reach what on the access map.

Served from /console, nothing extra to install. Everything it does is also available on the Management API.

05 · Developers

Documented, predictable and scriptable

What it is like to build against. Every error has the same shape, every response carries a request ID, and the whole setup can live in one reviewed YAML file.

error.json403 forbidden
403 {
  "error": "key may not run this query",
  "code": "forbidden",
  "request_id": "req_01J9…"
}

Interactive docs and a catalogue

/docs lists every saved query as its own endpoint with typed parameters; /catalog tells each caller what it can call and on what terms: cached, writable, its rate limit.

Stable error codes

Every error has the same shape: error, a code and a request_id. Codes are part of the compatibility promise: an existing one is never renamed or repurposed.

HTTP done properly

ETag and 304 Not Modified on cached responses, If-Match for safe concurrent edits, X-Has-More and X-Row-Count for paging, and ?timeout per request.

Typed clients

OpenAPI 3.0, validated in CI, turned into a client in about 50 languages by OpenAPI Generator; a Postman collection per collection.

06 · OperatePathGo to production →

Every run recorded, every change audited

Run history is per query and per key, with duration, rows and what was masked. The audit log records who changed what, by named administrator. Alerts are live conditions, worked out on each request and gone once the cause is.

Run history

When, which connection, which key, through which front door, how long, how many rows. Ad-hoc and MCP runs too.

Audit log

Timestamp, actor, action, target and the fields that changed, each entry chained to the one before. Secrets appear as "changed", never their value.

Request IDs

Every response carries X-Request-Id; every log line written for it carries the same.

Alerts

GET /api/v1/alerts
critical
open_server · connection_failing · sso_unreachable · audit_chain_broken · secret_provider_failingNo key configured; a connection's last runs all failed; nobody can sign in; the audit log was edited; Vault or AWS stopped answering.
warning
key_expiring · query_slow · query_errors · writes_awaiting_approval · quota_nearly_used · agent_unusual_volume · export_failing · audit_delivery_behindA key expires within 7 days; a query's median run is over threshold; agents' writes wait for a person; a quota is 80% used; an agent reads ten times its usual volume; an export or the SIEM stream falls behind.
info
key_unusedAn active key unused for 90 days.

Also watched: break_glass_used, key_expired, query_timeouts, key_rate_limited, client_rate_limited, history_failed, history_dropped, instances_not_shared, instances_versions_differ, rate_limits_not_shared, encryption_key_rotation_incomplete. 25 kinds in all.

Shown on the Console's Alerts screen, the bell in its header, and Home's System health. For paging, scrape /metrics with Prometheus.

Operations

Store

A SQLite file by default, or PostgreSQL for several instances. Versioned schema with upgrades tested in CI, backup and restore, passwords encrypted at rest.

Scale out

Redis, optional: one cache, one rate-limit budget and one event stream across every instance. If Redis blinks, limits stay enforced per process.

Observe

Structured logs with request IDs, per-key metrics, a Prometheus /metrics endpoint behind a token, a bundled Grafana dashboard, and OpenTelemetry spans Exp from the request to the database call, never holding a value or a row.

Deploy

pip, the image on ghcr (with an -h2 variant including Java), a Helm chart for one pod or several, and a multi-instance Compose setup behind Caddy. Non-root, read-only root filesystem.

Configuration as code

config export, config diff and config apply: the whole setup as one YAML file with no secret in it, reviewed in a pull request and applied all or nothing, by CI or at startup.

Secrets

Passwords encrypted at rest under a key you can rotate, or no password at all: ${file:…}, ${vault:…} and ${aws-sm:…} references, short-lived credentials from Vault or RDS IAM. AWS paths experimental.
