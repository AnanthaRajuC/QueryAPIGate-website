Deploy

Three reference architectures, each one tested in CI

Start with one instance on SQLite. Move to several on PostgreSQL and Redis when you need availability, or install the Helm chart. Instances are interchangeable, so moving between shapes is a configuration change, not a migration project.

QUERYAPIGATE_API_KEY=… One process or container. The store is SQLite on a volume; nothing else to set.
02+ High availability
QUERYAPIGATE_DATABASE_URL=postgres://… QUERYAPIGATE_REDIS_URL=redis://… A shared PostgreSQL store and Redis, so any instance answers any request and limits are counted once. Run queryapigate events behind the proxy for live events. Guide 42 →

Measured, not promised
