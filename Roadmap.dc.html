What 1.0 means

The version number becomes a contract. Everything listed in the compatibility promise freezes; experimental features graduate on written terms or stay labelled.

  • ✓Management API v1 — the last change before the freeze (named administrators) shipped in 0.16.
  • ✓Deprecation policy, experimental label, support matrix — 0.14.
  • ✓Deployment shape decided — one instance, or several on PostgreSQL + Redis, both tested in CI. 0.15.
  • ✓Every 0.x store upgrades or refuses clearly, tested in CI with real fixtures.
  • ✓Graduate or label — MCP OAuth, descriptions, agent usage, quotas, Console SSO, agent writes, configuration as code and the Helm chart graduated in 0.30; the SIEM stream in 0.32; live events and secrets from files and Vault in 0.34. H2, JDBC, MongoDB, tracing and AWS secrets stay labelled experimental.
  • ✓Signed releases — image and chart signed, with provenance and an SBOM. 0.31.
  • ✓Live events graduate — on the dedicated event log (0.33), stable in 0.34.
  • ○AWS secrets tested against AWS, then they graduate or stay labelled.
