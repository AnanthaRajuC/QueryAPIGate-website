For operations screens

A live view of what is being queried, by whom

A wall display or a client that reacts when a query runs. GET /events streams each run as it completes, per key if you want, fanned out across instances by the events server.

✓Server-sent events over plain HTTP: a fetch stream in the browser with the key in a header, no WebSocket infrastructure.
✓Per-key feeds, so a partner can watch their own calls and nobody else's.
✓Across several instances, queryapigate events reads every instance's runs from the shared store, woken by a PostgreSQL notification.
✓Stable since 0.34, under the compatibility promise. Filter by query, connection, kind or status.

const res = await fetch("https://data.example.com/events", {
  headers: {"X-API-Key": key}
})
const reader = res.body.pipeThrough(new TextDecoderStream()).getReader()
for (let buf = ""; ;) {
  const {value, done} = await reader.read(); if (done) break
  const frames = (buf += value).split("\n\n"); buf = frames.pop()
  for (const f of frames) {
    const line = f.split("\n").find(l => l.startsWith("data: "))
    if (line) onRun(JSON.parse(line.slice(6)))
  }
}
